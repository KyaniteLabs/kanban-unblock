# kanban-unblock

Hermes plugin: **Kanban Unblock Pane** (hackathon Proposal G / KLH-329).

Answer blocked `needs_input` kanban cards in place — a **Needs input** control inside the native Desktop `/kanban` page, plus `/kanban-unblock`, tools, and a queue brief. Shell/code approvals stay with catalog **needs-you** (refused here).

Tests: `tests/` (pytest vs Hermes ≥0.21.6, jsdom for the desktop half).

See [`plugins/kanban-unblock-hermes/`](./plugins/kanban-unblock-hermes/).
